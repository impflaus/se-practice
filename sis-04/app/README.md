# Smart Campus Room Availability Checker

A React + TypeScript application for finding rooms by capacity and equipment and checking room availability.

## Setup

Install dependencies:

```bash
npm install
```

## Run

Start the development server:

```bash
npm run dev
```

## Test

Run all automated tests:

```bash
npx vitest run
```

## Build

Create a production build:

```bash
npm run build
```
